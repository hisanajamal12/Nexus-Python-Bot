# 🤖 Nexus-Python-Bot 📂

Welcome to **Nexus-Python-Bot**, a multi-utility Python platform built for the **Elite Coders Open Source Hackathon 2026**. This repository contains a suite of lightweight, automated tools designed to enhance productivity.

## 🚀 Features

### 1. Rule-Based Intelligent Chatbot (`chatbot.py`)
A fast, interactive command-line assistant that responds to user inputs using dynamic conditional logic.
* **Key Concepts:** Loops, conditional matching, text processing.

### 2. Task Automation Script (`file_manager.py`)
An automated folder cleaning script that instantly scans a directory and organizes cluttered files into neat, dedicated folders.
* **Key Concepts:** File handling, `os`, `shutil` libraries, directory optimization.
